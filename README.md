# Sales Management System

A desktop application designed to help businesses manage sales, inventory, and customer records efficiently.

## Features
- Add and manage customer profiles
- Track inventory and product stock levels
- Record and analyze daily sales transactions
- Generate simple reports

## Tech Stack
- **Language:** Java
- **GUI Framework:** JavaFX (designed with Scene Builder)
- **Database:** MySQL
- **IDE:** NetBeans

## Setup Instructions
1. Clone or download the repository
2. Open the project in NetBeans or IntelliJ IDEA
3. Set up the MySQL database (create tables using the provided SQL scripts if available)
4. Update database connection details in the source code
5. Launch the application
